# ADR 0001: Выбор инструментов

Статус: принято

| Задача | Выбор | Причина |
|---|---|---|
| CI | GitHub Actions | Встроен в GitHub, не требует отдельной инфраструктуры |
| Линтер/форматтер | Ruff | Один инструмент вместо нескольких, быстрый |
| Тесты | pytest + pytest-cov | Стандарт де-факто для Python |
| Проверка Dockerfile | Hadolint | Специализированный линтер Dockerfile |
| Сканирование образа | Trivy | Бесплатный, есть официальный GitHub Action |
| Реестр образов | GHCR | Авторизация через `GITHUB_TOKEN`, без отдельных секретов |
| Обновление зависимостей | Dependabot | Встроен в GitHub, обновляет в том числе версии Actions |

## Как адаптировать под другой язык
Заменить job `lint` и `test` в `.github/workflows/ci.yml` на команды вашего стека
(npm/go/maven и т.д.). Шаги `build-scan` и `publish` от языка не зависят, если в
репозитории есть `Dockerfile`.
